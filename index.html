TrajAI-Defense

물리 제약 신경망 기반 실시간 탄도 궤도 예측 및 위협 평가 시스템

요격 체계의 교전 판단은 표적의 탄착점(IP)과 탄착 시각(ToT)을 얼마나 빨리, 얼마나 믿을 수 있게 아느냐에 달려 있습니다. 확장 칼만 필터(EKF)나 수치 적분 기반 예측은 대기 밀도 변화, 마하수에 따른 항력 변화, 기동이 있으면 연산 비용과 추정 오차가 함께 커집니다. 순수 데이터 기반 신경망은 빠르지만 관측이 적은 초기 구간에서 운동 방정식을 위반하는 궤적을 출력할 수 있습니다.

TrajAI-Defense는 비행 초기 10~15% 구간의 레이더 트랙을 시계열 인코더(Transformer / Bi-LSTM)로 요약하고, 운동 방정식 잔차를 손실에 포함한 물리 제약 신경망(PINN)으로 잔여 궤적, IP, ToT, CEP를 추론합니다. 목표는 단일 표적 추론 50 ms 이하, 기존 대비 CEP 추정 오차 40% 감소입니다. 이 문서는 운용 개념, 동역학 모델, 추정 문제 정식화, 학습 설계, 데이터셋, 검증 방법과 실험 결과를 정리합니다. 현재 결과로는 지연 목표는 충족하지만, 신경망 단독의 정확도는 같은 물리 모델을 쓰는 EKF/UKF에 못 미칩니다. 대신 PINN의 탄도계수 예측을 EKF의 사전정보로 넣으면 모든 시험 조건에서 EKF보다 정확해집니다(§9.6). 선택 일자의 실제 기온·바람을 대기 모델에 반영하면 IP 오차가 크게 줄어(§9.3) 이를 기본 설정으로 채택했습니다.

§1

궤도 추정 시연: 물리 기반 Baseline

아래 시연은 PINN이 대체하려는 기준 문제를 브라우저에서 직접 계산합니다. 7차원 상태(위치, 속도, ln β)의 확장 칼만 필터(EKF)가 잡음 섞인 레이더 트랙을 순차 처리해 관측 종료 시점의 상태와 공분산을 추정하고, 그 사후분포에서 표본을 뽑아 Monte Carlo로 IP 분포와 CEP를 구합니다. 관측 구간을 줄이거나 센서 잡음을 키우면 분산이 어떻게 커지는지 확인할 수 있습니다.

관찰 포인트. 대기 밀도가 높은 상승 초기에는 항력 감속이 측정되어 EKF의 β 공분산이 빠르게 줄어듭니다(가운데 그래프). 고도가 올라가 항력 가속도가 잡음 수준 아래로 떨어지면 β를 관측할 수 없게 되어 공분산이 더 줄지 않고, 이 불확실성이 재진입 구간에서 하향거리 분산으로 증폭됩니다. 짧은 관측에서 학습된 사전정보로 이 공백을 메우는 것이 PINN의 역할입니다.

9.2해석

물리 손실은 궤적의 물리 일관성을 확실히 높입니다. 같은 v2 학습 조건에서 ID 10%의 물리 잔차 RMS가 0.40 g(data only)에서 0.10 g(PINN)로 줄었고, IP 오차도 794 m에서 733 m로 줄었습니다. 잡음 증강 하이브리드(v2)의 잔차는 0.086 g입니다. IP 오차 이득은 분할에 따라 갈립니다. ID 10%, OOD 12%에서는 PINN이 더 작고, ID 5%, ID 15%, ID 고잡음에서는 data-only와 같거나 더 큽니다. 물리 손실의 확실한 효과는 궤적의 물리 일관성(잔차)이며, 정확도 이득은 조건부입니다(유의성은 §9.4). REQ-F-03의 목표(0.05 g)에는 아직 못 미칩니다.

EKF 정보 결합이 가장 효과가 큽니다. EKF 사후 상태를 입력으로 받는 하이브리드(ID 15% 428 m)와 EKF-RTS 평활 특징을 입력으로 받는 PINN(ID 15% 317 m, §9.6)은 모두 PINN 단독(645 m)보다 정확하며, 필터가 단기 상태를, 신경망이 장기 궤적을 맡는 Table 6의 구조를 뒷받침합니다.

정확도는 아직 고전 필터에 못 미칩니다. 신경망의 최선 IP 오차(ID 15% 317 m, PINN-Transformer (RTS 입력))는 EKF(225 m)와 UKF(212 m)보다 큽니다. 모델 불일치가 없는 합성 환경에서는 정확한 물리 모델을 가진 필터가 상한에 가깝기 때문입니다. 신경망의 이점은 현재로서는 정확도보다 지연(약 262배)과 일정한 추론 시간에 있습니다. 예외는 고잡음 조건으로, RTS 입력 PINN(607 m)이 EKF(629 m)보다 정확합니다.

분포 이동에 취약합니다. 학습 분포 밖의 OOD 조건에서는 모든 신경망의 IP 오차가 10 km 이상으로 커지고 CEP 포함률이 0.1 수준으로 떨어집니다. 반면 EKF/UKF는 물리 모델이 그대로 성립하므로 영향이 작습니다. 물리 잔차를 손실에 넣는 것만으로는 외삽 일반화가 보장되지 않는다는 결과입니다.

12.1기상 영향 분석과 교전 우선순위

기상 영향 분석은 한 비행 조건을 정한 위치(0.25° 격자)와 기간(최대 7일 × 하루 4회)의 실제 기상 속으로 날려, 같은 레이더 측정을 표준 대기 EKF와 그 시각 기상 EKF로 각각 추정합니다. 결과는 데이터베이스(weather_analyses)에 저장되어 다시 열어 볼 수 있습니다. 2026-10-13–19(28개 프로파일, 중부)에서 기상을 반영한 추정의 IP 오차 감소는 저β 단거리 98%(2,210 → 45 m), 기준 비행 95%(5,132 → 281 m)였고, 2026-01-12–16 겨울 제트기류 속 고β 장거리는 16%(555 → 469 m)에 그쳤습니다. 탄도계수가 클수록 항력, 곧 대기의 영향이 작다는 식 (5.5)의 예상과 일치합니다. 이 분석의 기상 반영 EKF는 비행에 쓰인 프로파일을 그대로 받으므로 분석장 오차가 없는 낙관적 조건이며, 오차를 넣은 평가는 §9.3에 있습니다.

교전 우선순위는 시나리오마다 가장 정확한 최신 추정(§9.4 순서: 기상 반영 EKF → UKF → PINN → 표준 EKF)을 골라 위협 등급, 탄착 확률, 남은 시간, 교전 창이 열리기까지의 시간 순으로 정렬합니다.

범위 밖으로 둔 기능. 목표 지점과 발사 후보지를 주고 기상 조건에 따라 발사 시각과 위치를 고르는 기능은 검토했으나 넣지 않았습니다. 들어오는 표적을 예측해 방어 판단을 돕는다는 이 시스템의 목적과 반대 방향(공격 측 계획)이기 때문입니다. 같은 기상 자료를 방어 쪽에서 쓰는 방식이 위의 기상 영향 분석입니다.
