## 예상 질문과 답

- **실측 데이터 없이 믿을 수 있나요?** 레이더 실측은 비공개라 구할 수 없었습니다. 대신 6-DOF 진값, 활공 기동, 공개 실측 재진입 궤적(Hayabusa)으로 가정이 깨질 때를 시험했고, 실패한 결과(활공 기동 약 35 km)도 공개했습니다.
- **PINN이 EKF보다 낫다는 건가요?** 물리 손실만으로는 아닙니다. 잔차는 76% 줄지만 RMSE는 비슷합니다. RTS 평활 입력과 학습 2배를 더해야 RMSE 686 m로 EKF(747 m)보다 낮아지고, 가장 큰 개선은 PINN의 β를 EKF 사전정보로 쓰는 결합(−33%)이었습니다.
- **분포 밖 입력이면요?** 신경망 오차는 11.7 km까지 커집니다. 내부 표현 거리로 99.8%를 감지해 EKF로 넘기면 439 m입니다.
- **해킹되면 국방 정보가 새지 않나요?** 공개 데모에는 합성 데이터와 가상 자산만 있습니다. 서버는 운영 모드에서 약한 설정이면 기동을 거부하고, 매 커밋마다 보안 검사가 돕니다. 실제 배치 요건(내부망, KCMVP, 다중 인증)은 보고서에 정리했습니다.
